# 📊 Superstore Sales Analysis Dashboard

## 📌 Project Overview
This project is an interactive **Superstore Sales Analysis Dashboard** created using **Microsoft Power BI**. The dashboard helps analyze sales, profit, quantity, categories, regions, products, and shipping modes.

## 🎯 Project Objective
The main objective of this project is to analyze Superstore data and gain useful business insights through interactive data visualizations.

## 🛠️ Tools Used
- Microsoft Power BI
- Data Analysis
- Data Visualization
- Excel/CSV Dataset

## 📈 Dashboard Features
- 💰 Sales Analysis
- 📊 Profit Analysis
- 🌍 Region-wise Sales Analysis
- 📦 Category-wise Sales Analysis
- 🚚 Ship Mode Analysis
- 📅 Monthly Sales Analysis
- 🛍️ Product-wise Profit Analysis
- 🗺️ Geographic Sales Visualization
- 🔍 Interactive Filters and Slicers

## 📊 Key Insights
The dashboard provides a clear view of Superstore business performance and helps identify trends in sales, profit, categories, regions, and products.
